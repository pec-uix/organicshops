# Ticket：/cart 頁商品列促銷標籤一致化與買一送一贈品列呈現

## 本次目的

將 `/cart` 頁商品清單的促銷身份標籤整理一致，並在符合買一送一條件的商品下方插入附屬贈品列。

本次僅處理 `src/views/CartView.vue` 的前端視覺渲染，不修改 Vuex store、不修改商品資料結構、不修改價格、折扣、運費、OPENPOINT 點數或結帳計算。

## 調整範圍

| 區域 | 檔案 | 調整內容 |
|---|---|---|
| 購物車頁 | `src/views/CartView.vue` | 商品名稱前加入促銷身份標籤 |
| 購物車頁 | `src/views/CartView.vue` | 買一送一商品下方新增附屬贈品列 |
| 購物車頁 | `src/views/CartView.vue` | 加價購名稱前方標籤一致化 |

## 標籤規則

- 一般商品：不顯示標籤。
- 買一送一主商品：商品名稱前顯示 `買 1 送 1`。
- 加價購商品：商品名稱前顯示 `加價購`。
- 滿額贈商品列：維持現有 `贈品` 標籤。

## 判斷方式

- 買一送一主商品：
  - 只沿用現有已存在的促銷欄位或 `tags` 資料，不新增新的規則。
  - 若商品 `tags` 包含 `買1送1`，則主商品列顯示 `買 1 送 1`。
- 加價購商品：
  - 若商品 `id` 以 `addon-` 開頭、`tags` 包含 `加價購`，或名稱帶有 `[加價購]`，則顯示 `加價購` 標籤。
  - 若名稱本體已含 `[加價購]`，畫面顯示時移除前綴，只保留名稱前方的 `加價購` 標籤。

## 買一送一贈品列

- 若 `getGiftQuantity(item.product, item.quantity) > 0`，顯示附屬贈品列。
- 若商品屬於買一送一標記商品，贈品數量依主商品數量顯示。
- 贈品列緊貼主商品列下方。
- 不要放到整個商品清單最後。
- 不要放到滿額贈商品列附近。
- 不要放到免運進度條、結帳明細或加價購區塊。

### 視覺規格

- 圖片沿用主商品圖片。
- 名稱沿用主商品名稱。
- 規格沿用主商品 `unit`。
- 數量顯示 `getGiftQuantity(item.product, item.quantity)` 或對應的既有結果。
- 單價與小計顯示 `$0`。
- 名稱前方顯示 `贈品` 標籤。
- 不顯示數量加減器、刪除按鈕、加入購物車按鈕或 OP 點數。

## 不在本次處理

- 不修改 `CartDrawer.vue`。
- 不修改 `CheckoutView.vue`。
- 不修改 Vuex store。
- 不修改商品價格、折扣、運費、OPENPOINT 點數或結帳計算。
- 不改滿額贈邏輯與滿額贈商品列。

## 驗收條件

- 買一送一主商品名稱前顯示 `買 1 送 1` 標籤。
- 加價購商品名稱前顯示 `加價購` 標籤，且不重複顯示 `[加價購]` 前綴。
- 一般商品不顯示促銷標籤。
- 符合買一送一的商品下方顯示附屬贈品列。
- 買一送一贈品列緊貼主商品，不會跑到商品清單底部。
- 買一送一贈品列數量會依主商品數量更新。
- 買一送一贈品列顯示 `$0`，沒有加減、刪除、加入購物車操作。
- 滿額贈商品列維持目前行為與樣式。
- `npm run build` 通過。
