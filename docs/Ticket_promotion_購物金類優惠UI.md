# Ticket：購物金類優惠 UI 呈現

## 目標

補齊購物金類優惠在目前 Vue prototype 的前台呈現，包含加入送購物金、滿額送購物金、首購送購物金、套餐送購物金，並明確區分「購物金折抵」與「購物金獲得」。

2026-07-10 調整：會員中心購物金頁不再顯示「購物金來源」卡片，避免在會員明細頁重複呈現活動規則；來源示例保留於交易流程與訂單回查的回饋呈現。

## 範圍

- 會員中心購物金頁保留餘額、到期提醒、異動紀錄與使用說明，不顯示購物金來源卡。
- 購物車顯示本次預計獲得購物金。
- 結帳確認頁顯示本次訂單可獲得購物金。
- 訂單明細顯示購物金回饋紀錄。
- 購物金折抵維持在折抵明細；購物金獲得以正向回饋區塊呈現。

## Mock 回饋來源

| 類型 | 條件 | 回饋 |
| --- | --- | --- |
| 加入送購物金 | 加入會員 | $50 |
| 滿額送購物金 | 單筆商品小計滿 $1,800 | $100 |
| 首購送購物金 | 首次完成訂單 | $150 |
| 套餐送購物金 | 購買指定套餐 | $80 |

## 驗收標準

- 會員中心購物金頁不顯示四種購物金來源卡，頁面聚焦可用餘額、到期提醒與明細紀錄。
- 購物車結帳明細顯示本次預計獲得購物金，且不影響付款金額。
- 結帳確認頁顯示本次訂單可獲得購物金。
- 訂單明細可看到購物金回饋紀錄。
- 購物金「折抵」與「獲得」分區呈現，不混在同一列。

## Vuetify 對應建議

- 回饋明細：`v-list`
- 金額摘要：`v-card` + `v-chip`
- 訂單回饋紀錄：`v-data-table` 或 responsive `v-list`
