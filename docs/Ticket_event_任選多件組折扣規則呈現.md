# Ticket：任選多件組活動專區新增三種任選折扣規則呈現

## 本次目的

在「任選多件組」活動專區補上三種任選活動卡，讓設計審稿時能直接看到不同任選折扣規則的前台呈現方式。

本次只處理活動專區視覺呈現，不調整購物車折扣、結帳金額或優惠計算。

## 調整範圍

| 區域 | 檔案 | 調整內容 |
|---|---|---|
| 任選多件組活動頁 | `src/views/EventView.vue` | 新增任選規則資訊帶 |
| 任選多件組活動頁 | `src/views/EventView.vue` | 新增「任選享折數」示例卡 |
| 任選多件組活動頁 | `src/views/EventView.vue` | 新增「任選折固定金額」示例卡 |
| 任選多件組活動頁 | `src/views/EventView.vue` | 新增「任選每件折固定金額」示例卡 |

## 新增呈現

- 任選享折數：堅果果乾任選 3 件 85 折。
- 任選折固定金額：早餐穀粉任選 4 件折 $120。
- 任選每件折固定金額：銀髮飲品任選 6 件，每件折 $10。

## 顯示規則

- 活動卡標籤直接顯示優惠類型與門檻。
- 卡片中段顯示任選規則、可選商品範圍與示例折抵結果。
- 價格區顯示原價與活動價。
- 頁面不顯示工程限制或內部備註。

## Vuetify 對應建議

- 活動卡：`v-card`
- 優惠標籤：`v-chip`
- 任選規則資訊帶：`v-sheet`
- 價格區：`v-card-actions` 或自訂 summary row
- 選購按鈕：`v-btn`

## 驗收條件

- 進入 `/event/SUMMER2026?group=flash&item=flash-bundle` 可看到三張新增任選折扣規則卡。
- 三張卡分別能辨識為任選享折數、任選折固定金額、任選每件折固定金額。
- 每張卡都有原價、活動價與折扣說明。
- `npm run build` 通過。
