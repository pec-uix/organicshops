# Ticket：任選組合類優惠 UI 呈現

## 目標

補齊任選組合類優惠在目前 Vue prototype 的前台呈現，包含任選固定金額、A+B+C 組合、指定件數固定價，讓活動專區、組合選購頁、商品詳情、購物車、結帳摘要與訂單回查保留一致的組合資訊。

## 範圍

- 任選多件組活動專區新增三張組合活動卡。
- 組合選購頁依活動顯示分區、已選件數、尚差件數、原價、折抵與活動價。
- 商品詳情從活動頁進入時保留任選活動提示區。
- 購物車以組合商品列顯示組合價，並展開組合內容摘要。
- 結帳摘要顯示組合商品內容，不拆改正式結帳金額邏輯。
- 訂單回查保留組合商品名稱、組合價與組合內商品明細。

## Mock 活動

| 類型 | 活動 | 條件 | 活動價 |
| --- | --- | --- | --- |
| 任選固定金額 | 堅果果乾任選3件固定$999 | 任選商品滿 3 件 | $999 |
| A+B+C 組合 | A+B+C 日常保養組合$1,290 | A、B、C 三區各 1 件 | $1,290 |
| 指定件數固定價 | 指定商品任選3件固定$390 | 指定商品任選 3 件 | $390 |

## 驗收標準

- 活動專區可看到任選固定金額、A+B+C 組合、指定件數固定價三張活動卡。
- 點入組合選購頁後，可看到目前已選件數、各區尚差件數、原價、折抵與活動價。
- 未達門檻時加入購物車按鈕顯示尚差件數，達成後可加入購物車。
- 購物車商品列顯示組合購標籤、組合商品內容與組合價。
- 結帳摘要保留組合內容摘要。
- 訂單回查可看到組合商品列與組合內品項。

## Vuetify 對應建議

- 活動卡：`v-card`、`v-chip`、`v-img`
- 組合分區：`v-row`、`v-col`、`v-card`
- 件數控制：`v-btn`、`v-chip`
- 組合摘要：`v-card`、`v-list`
- 訂單明細：`v-data-table` 或 responsive `v-list`
