# Design Pass: 關於我們內容調整

## 範圍

- 頁面：`/about`
- 檔案：`src/views/AboutView.vue`
- 目標：參考統一生機購物網「關於我們」正式內容，更新 prototype 的品牌介紹頁文案與資訊架構。

## 內容來源方向

- 企業簡介
- 企業定位、使命、願景、文化、核心價值、經營理念
- 企業標誌與色彩意義
- 產品與通路
- 服務時間
- 品質把關

## UI 調整

- 改為企業內容頁形式，不使用原本過度簡化的品牌故事卡片。
- 頁首 Banner 改為與最新消息頁一致的背景圖、白色柔和漸層、深色標題排版。
- 移除各區塊標題上方的英文 eyebrow 小字，讓頁面以中文標題為主。
- 使用品牌綠、白底、淺灰邊框與扁平卡片呈現資訊分組。
- 保留目前 prototype 的麵包屑樣式與清爽品牌視覺。
- 探索更多區塊保留導向最新消息、銷售通路與聯絡我們。
- 服務時間區塊放在品質把關下方，呈現免付費訂貨專線與愛用者服務專線。
- 探索更多標題改用與消息詳情頁「其他消息」一致的左側品牌綠線樣式。

## Vuetify Mapping

- 頁面容器：`v-container`
- 資訊卡：`v-card`
- 區塊排版：`v-row` / `v-col`
- 導覽卡：`v-card` + `v-btn`
- 色彩說明：`v-chip` 或自訂 swatch

## Acceptance Criteria

- `/about` 呈現正式網站關於我們的核心內容。
- 畫面不出現工程註記或 mock 說明。
- 企業資訊分區清楚，手機與桌機版可讀性良好。
