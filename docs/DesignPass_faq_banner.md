# Design Pass: 常見問題 Banner 調整

## 範圍

- 頁面：`/faq`
- 檔案：`src/views/FaqView.vue`

## UI 調整

- 將原本白底頁首改為與 `/news` 一致的 Banner 呈現。
- 使用 `images/背景圖.png` 作為背景圖。
- 使用柔和白色漸層、深色中文標題與深灰副標。
- Banner 下方改為正式站相近的內容架構：
  - 麵包屑
  - sticky 分類橫向導覽
  - 各分類標題
  - 問答手風琴列表
  - 聯絡客服引導
- 視覺維持目前 prototype 的品牌綠、白底、淺灰邊框與扁平卡片風格。
- FAQ 文字內容參考統一生機購物網 `page.aspx?page=fq`，整理為訂購、購物金、OPENPOINT、付款、安全與發票問題。
- FAQ 問答與分類容器限制為 `max-w-6xl`，約 1152px。
- 分類導覽可平滑滾動至對應區塊，並依目前區塊高亮。
- 手風琴列上下內距調整為 14px，hover 使用極淡灰背景與箭頭微動效果。
- FAQ 文字色階採三層配置：大分類標題 `#111827`、問題列 `#374151`、回答內文 `#4B5563`，展開與 hover 時切換為品牌綠 `#719E37`。

## Acceptance Criteria

- `/faq` 第一屏呈現與最新消息頁一致的 Banner 視覺。
- 常見問題分類可由上方導覽快速前往。
- 常見問題清單可展開與收合。
- 分類標題使用全站主要字體，不另外套用 serif 字體。
- 所有 FAQ 預設為收合狀態。
- 畫面不出現工程註記。
