# Ticket：/cart 頁折扣碼套用按鈕與狀態提示

## 本次目的

將購物車頁的折扣碼輸入從即時生效，調整為「輸入草稿」與「點擊套用後生效」分離。

目標是讓使用者在輸入過程中不會立即改變折抵金額，必須點擊套用後才更新目前溫層的折扣碼折抵。

## 調整範圍

| 區域 | 檔案 | 調整內容 |
|---|---|---|
| 購物車頁 | `src/views/CartView.vue` | 折扣碼輸入框新增套用按鈕 |
| 購物車頁 | `src/views/CartView.vue` | `couponCode` 保留為輸入草稿 |
| 購物車頁 | `src/views/CartView.vue` | 新增各溫層 `appliedCouponCode` 作為實際折抵來源 |
| 購物車頁 | `src/views/CartView.vue` | 新增成功、錯誤、取消狀態提示 |

## 顯示與互動規則

- 使用者輸入折扣碼時，不立即改變折抵金額。
- 點擊「套用」後，才檢查折扣碼是否可用。
- 可用時，更新該溫層已套用折扣碼並顯示成功提示。
- 查無可用折扣碼時，不改變原本已套用折抵，並顯示前台錯誤提示。
- 清空輸入框後點擊套用，清除該溫層已套用折扣碼。
- 點擊套用後讓輸入框失焦，方便手機收合虛擬鍵盤。

## RWD 規則

- 桌機版：輸入框與套用按鈕同列。
- 手機版：輸入框與套用按鈕上下排列，套用按鈕滿版寬度。
- 提示文字使用低干擾 `text-xs`。

## 不在本次處理

- 不調整 `CheckoutView.vue`。
- 不調整 Vuex cart store、折扣、運費、OPENPOINT 點數或結帳計算邏輯。
- 不修改折價券下拉選單規則。

## 驗收條件

- 輸入折扣碼但未按套用時，折抵金額不變。
- 有效折扣碼套用後，折扣碼折抵金額才更新。
- 無效折扣碼顯示「查無可用折扣碼，請重新輸入。」。
- 清空輸入框後套用，可取消該溫層折扣碼。
- 切換溫層時，各溫層保留自己的草稿與已套用折扣碼。
- `npm run build` 可通過。
