# Ticket：買送類優惠 UI 呈現

## 目標

補齊買送類優惠在目前 Vue prototype 的前台呈現，包含買2送1、買2送2、買A送B，讓活動專區、商品卡、商品詳情、購物車、結帳摘要與訂單回查能使用一致的促銷文字與贈品列樣式。

## 範圍

- 活動專區「任選多件組」新增買送類活動卡。
- 商品卡顯示買送標籤：買 2 送 1、買 2 送 2、買 A 送 B。
- 商品詳情使用既有促銷提示區顯示買送文案與達成狀態。
- 購物車符合條件時顯示贈品列，贈品單價與小計為 $0。
- 結帳摘要顯示本次贈品。
- 訂單列表展開與訂單明細可看到贈品列，並顯示買送類來源標籤。

## 驗收標準

- 活動專區可看到三張買送類活動卡，且每張卡包含規則、適用商品、贈品內容與 $0 贈品提示。
- 商品列表與商品詳情頁可看出商品適用的買送優惠。
- 購物車加入符合條件數量後，贈品列出現在商品列下方，價格欄維持 $0。
- 結帳摘要的贈品區會列出符合條件的贈品名稱、數量與活動標籤。
- 訂單回查的贈品列可分辨滿額贈與買送類贈品。

## Vuetify 對應建議

- 活動卡：`v-card`、`v-chip`、`v-img`
- 商品標籤：`v-chip`
- 贈品列：`v-list-item` 或 `v-row` / `v-col`
- 結帳摘要：`v-card` + `v-list`
- 訂單明細：`v-card` + `v-data-table` 或 responsive `v-list`
