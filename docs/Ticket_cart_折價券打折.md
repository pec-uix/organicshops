# Ticket：購物車新增折價券打折示例

## 本次目的

在 `/cart` 的「選擇折價券」區塊新增一張百分比折價券，呈現折價券打折的前台狀態。

## 調整範圍

| 區域 | 檔案 | 調整內容 |
|---|---|---|
| 購物車頁 | `src/views/CartView.vue` | 折價券資料支援固定金額與百分比折扣 |
| 購物車頁 | `src/views/CartView.vue` | 新增「會員感謝 9 折券」 |
| 購物車頁 | `src/views/CartView.vue` | 折價券下拉文字改依折扣型態顯示 |

## 顯示規則

- 固定金額券顯示 `折抵 $X`。
- 百分比券顯示 `9 折`。
- 選到百分比券後，依目前溫層商品小計計算本次折抵金額。

## 驗收條件

- `/cart` 折價券下拉可看到「會員感謝 9 折券」。
- 達門檻後可選取此券並顯示本次折抵金額。
- 固定金額券維持原本顯示與折抵。
- `npm run build` 通過。
