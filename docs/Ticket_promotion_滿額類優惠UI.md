# Ticket：滿額類優惠 UI 呈現

## 目標

補齊滿額類優惠在目前 Vue prototype 的前台呈現，包含多門檻滿額贈、滿額自動折扣、滿額自動折價，讓購物車、結帳摘要與訂單回查能清楚呈現達成狀態與折抵來源。

## 範圍

- 購物車依溫層顯示滿額進度。
- 常溫購物車顯示多門檻滿額贈。
- 常溫購物車顯示滿 $1,800 享 95 折。
- 常溫購物車顯示滿 $1,800 現折 $50。
- 結帳摘要顯示自動折扣 / 自動折價來源與金額。
- 訂單回查顯示折抵明細與滿額贈品列。

## Mock 門檻

| 類型 | 門檻 | 呈現 |
| --- | --- | --- |
| 滿額贈 | 滿 $1,500 | 贈海苔薄切洋芋片、杏桃乾、原味腰果隨手包 |
| 滿額贈 | 滿 $2,000 | 加贈有機燕麥飲 |
| 滿額自動折扣 | 滿 $1,800 | 享 95 折 |
| 滿額自動折價 | 滿 $1,800 | 現折 $50 |

## 驗收標準

- 購物車常溫分區可看到滿額贈 1500 / 2000 兩個門檻的達成或尚差文案。
- 達到門檻後，購物車贈品列會列出對應贈品，贈品金額為 $0。
- 達滿 $1,800 後，購物車結帳明細列出 95 折與現折 $50。
- 結帳摘要列出自動折扣與自動折價來源。
- 訂單回查的折抵明細可看到滿額自動折扣 / 折價，商品明細可看到滿額贈品列。

## Vuetify 對應建議

- 滿額進度：`v-progress-linear`
- 門檻提示：`v-alert` 或 `v-list`
- 贈品列：`v-list-item`
- 金額明細：`v-card` + `v-list`
- 訂單折抵明細：`v-data-table` 或 responsive `v-list`
