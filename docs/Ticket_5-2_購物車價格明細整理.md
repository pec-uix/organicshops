# Ticket 5-2：購物車價格明細整理

## 本次目的

將購物車頁每個溫層的結帳前價格資訊整理成清楚的明細卡，讓使用者在前往結帳前可以確認：

- 商品小計
- 運費
- 折價券 / 折扣碼折抵
- OPENPOINT 需求
- 預估應付金額

## 調整範圍

| 區域 | 檔案 | 調整內容 |
|---|---|---|
| 購物車頁 | `src/views/CartView.vue` | 新增「結帳明細」卡片，整理小計、運費、折抵、OP 點數與預估應付金額 |
| 購物車頁 | `src/views/CartView.vue` | 折抵提示從單行提示改為已套用折抵狀態 |
| 購物車頁 | `src/views/CartView.vue` | 前往結帳按鈕移到明細卡旁，形成結帳前摘要區 |

## 顯示規則

- 商品小計：使用目前溫層商品加總。
- 運費：若達免運門檻顯示「免運」，否則顯示該溫層運費。
- 折抵：顯示目前折價券與折扣碼的加總折抵。
- OP 點數：目前溫層若有 OP 換購商品，顯示所需點數。
- 預估應付金額：商品小計 + 運費 - 折抵，最低為 0。

## 配送運費門檻提示

購物車頁可在各溫層免運進度條下方，以低干擾文字提示該溫層的配送門檻，方便使用者在前往結帳前確認。

| 溫層 | 配送方式 | 顯示文案 |
|---|---|---|
| 常溫 | 宅配 | 單筆訂單金額未滿 1200 元，需加收 120 元運費。 |
| 常溫 | 超取 | 單筆訂單金額未滿 599 元，需加收 60 元運費。 |
| 冷凍 | 宅配 | 單筆訂單金額未滿 800 元，需加收 120 元運費。 |
| 冷凍 | 超取 | 單筆訂單金額未滿 800 元，需加收 100 元運費。 |

呈現原則：

- 只在常溫與冷凍溫層顯示；冷藏與產地直送待正式門檻確認後再補。
- 提示不影響既有運費計算、免運進度條、折價券或結帳流程。
- 視覺使用輕量文字與細左線，不做厚重卡片或大面積底色。

## 不在本次處理

- 不修改購物車商品金額計算來源。
- 不修改折價券或折扣碼正式規則。
- 不修改購物金折抵。
- 不修改 OPENPOINT 實際扣點流程。
- 不修改結帳流程與後端 API。
- 不處理跨溫層合併付款。

## 驗收條件

- 使用者切換不同溫層時，可看到該溫層的結帳明細。
- 有折價券或折扣碼折抵時，明細會顯示負向折抵金額。
- 達免運門檻時，運費顯示「免運」。
- 有 OP 換購商品時，明細會顯示 OPENPOINT 需求。
- 畫面不出現 API、mock、後端串接等工程提醒。
