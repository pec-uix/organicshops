# Ticket：會員與次數類優惠 UI 呈現

## 目標

補齊會員與次數類優惠在目前 Vue prototype 的前台呈現，包含生日購物金、會員分級首筆訂單折扣、只要消費贈送一次、第 N 筆以上消費送贈品或購物金。

## 範圍

- 會員中心顯示生日優惠與會員分級優惠。
- 購物車顯示符合會員條件的優惠提示。
- 首筆訂單折扣在購物車與結帳摘要顯示。
- 消費一次 / 第 N 筆優惠顯示達成與未達狀態。
- 訂單回查顯示已使用的會員或次數優惠。

## Mock 會員狀態

| 類型 | 狀態 | 呈現 |
| --- | --- | --- |
| 生日購物金 | 生日月份 | 可領取 $200 |
| 會員分級首筆訂單折扣 | VIP 首筆訂單 | 9 折 |
| 只要消費贈送一次 | 本次消費可達成 | 贈品 1 份 |
| 第 3 筆消費 | 本次為第 3 筆 | 贈品已達成 |
| 第 5 筆消費 | 目前尚差 2 筆 | 購物金 $100 |

## 驗收標準

- 會員中心可看到生日禮、會員分級與消費次數優惠。
- 購物車顯示會員優惠狀態與 VIP 首筆訂單折扣。
- 結帳摘要顯示會員首筆訂單折扣與次數優惠狀態。
- 訂單明細可看到會員優惠折抵與已使用的會員 / 次數優惠紀錄。
- 畫面不出現工程註記或後端需求文字。

## Vuetify 對應建議

- 會員優惠卡：`v-card`、`v-chip`
- 優惠狀態列：`v-list`
- 金額明細：`v-card` + `v-list`
- 訂單回查：`v-data-table` 或 responsive `v-list`
