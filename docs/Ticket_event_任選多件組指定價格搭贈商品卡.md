# Ticket：任選多件組活動專區新增指定價格搭贈商品卡

## 本次目的

在活動專區的「任選多件組」頁面新增一筆商品卡示例，呈現指定價格搭贈與買一送一的前台顯示方式。

本次只處理活動頁視覺呈現，不調整購物車折扣、結帳金額或贈品計算。

## 調整範圍

| 區域 | 檔案 | 調整內容 |
|---|---|---|
| 任選多件組活動頁 | `src/views/EventView.vue` | `bundleProducts` 新增「原味綜合堅果隨手包指定價格搭贈組」 |
| 任選多件組活動頁 | `src/views/EventView.vue` | 組合商品卡支援顯示搭贈內容區塊 |

## 顯示規則

- 商品卡標籤顯示 `指定價格`、`買 1 送 1`。
- 商品描述用消費者可理解的活動文案呈現。
- 價格區顯示原價與售價。
- 若商品有搭贈資料，商品卡中段顯示「搭贈內容」。
- 搭贈列顯示贈品圖片、名稱、規格、數量與 `$0`。

## Vuetify 對應建議

- 商品卡：`v-card`
- 活動標籤：`v-chip`
- 圖片區：`v-img`
- 搭贈內容：`v-card` 內的次層 `v-row` / `v-col`
- 行動按鈕：`v-btn`

## 驗收條件

- 進入 `/event/SUMMER2026?group=flash&item=flash-bundle` 可看到新增的指定價格搭贈商品卡。
- 商品卡可清楚辨識這是買一送一活動。
- 搭贈商品以 `$0` 贈品列呈現。
- 頁面不出現工程註記或內部限制說明。
- `npm run build` 通過。
