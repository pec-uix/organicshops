# Design Pass: 購物須知 Banner 調整

## 範圍

- 頁面：`/shopping-guide`
- 檔案：`src/views/ShoppingGuideView.vue`

## UI 調整

- 頁首改為與 `/news` 一致的 Banner 結構。
- Banner 使用 `images/背景圖.png` 作為背景圖，並搭配柔和白色漸層。
- 標題與副標題改為深色字系，提升在明亮背景上的可讀性。
- Banner 下方補上麵包屑導覽，與站內其他內容頁一致。
- 內容區保持既有資訊架構，但容器寬度與 `/news` 對齊，改為 `max-w-6xl`。
- 購物流程區改為上方 1-6 選項列、下方共用內容框的切換式版型，避免六欄並排時互相干擾。
- 切換時同步更新下方說明內容，維持同一個閱讀焦點。
- 選項列視覺恢復上一版的圓點＋標題排列，保留目前的點選高亮與內容切換反應。
- 移除步驟區的輔助提示文字。
- 「運費與配送規則」與「注意事項」標題補上與第一段一致的左側綠線。
- 區塊間改用較明顯的灰色橫線分隔，不在標題下方使用分隔線。
- 運費與配送規則表格標頭改為淡綠底，列高微縮，提升精緻感。
- 整頁主要內容容器統一限制在 1100px 內。

## Acceptance Criteria

- `/shopping-guide` 首屏呈現 Banner。
- 標題、描述、麵包屑的層級與其他內容頁一致。
- 主要內容維持可讀且不過度拉寬。
- 畫面不出現工程註記。
