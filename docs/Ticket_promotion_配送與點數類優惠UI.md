# Ticket：配送與點數類優惠 UI 呈現

## 目標

補齊配送與點數類優惠在目前 Vue prototype 的前台呈現，包含超商取貨專屬優惠、滿額加贈 OP 點，並保留既有 OP 點換購行為，不與本次點數回饋混為同一種優惠。

## 範圍

- 購物車依配送方式切換時，顯示超商取貨專屬優惠。
- 超商取貨滿額送購物金、滿額加價購、滿額送贈品各做一個示例。
- 滿額加贈 OP 點顯示進度與達標狀態。
- 結帳摘要顯示本次可獲得 OP 點。
- 訂單明細顯示 OP 點回饋與超商取貨優惠。
- 保留既有 OP 點換購與購物金折抵區塊，避免混成同一類呈現。

## Mock 呈現

| 類型 | 呈現方式 |
| --- | --- |
| 超商取貨滿額加價購 | 顯示為可加購提示與門檻狀態 |
| 超商取貨滿額送購物金 | 顯示為購物金回饋提示 |
| 超商取貨滿額送贈品 | 顯示為贈品回饋提示 |
| 滿額加贈 OP 點 | 顯示門檻進度、達標狀態與可獲得點數 |

## 驗收標準

- 切換成超商取貨時，購物車可看見配送專屬優惠提示。
- 超商取貨的三種示例優惠都能在 UI 看到對應門檻與狀態。
- 滿額加贈 OP 點能在購物車與結帳摘要看到可獲得點數。
- 結帳摘要會把 OP 點回饋與 OP 換購分開呈現。
- 訂單回查可看到 OP 點回饋與超商取貨優惠紀錄。

## Vuetify 對應建議

- 配送切換：`v-tabs` 或 `v-btn-toggle`
- 優惠狀態：`v-alert`、`v-chip`
- 進度與門檻：`v-progress-linear`
- 回饋明細：`v-card` + `v-list`
- 訂單回查：`v-data-table` 或 `v-list`
