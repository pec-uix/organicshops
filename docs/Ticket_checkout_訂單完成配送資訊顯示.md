# Ticket: 訂單完成與訂單明細配送資訊顯示

## 類型

Functional Ticket

## 目標

調整訂單完成頁與訂單明細頁的配送資訊呈現，讓使用者看到的是結帳時填寫的希望配送日期，並簡化配送進度節點。

## 顯示規則

- 「預計到貨」優先顯示 checkout 填寫的希望配送日期。
- 若沒有填寫希望配送日期，「預計到貨」右側保持空白。
- 不再以固定文案顯示 2-3 個工作天或 3-5 個工作天。
- 配送進度只顯示三個節點：
  - 訂單確認
  - 備貨中
  - 已送達

## Prototype Scope

- checkout 送出訂單時帶出希望配送日期。
- 訂單完成頁從送出資料讀取希望配送日期。
- 訂單明細頁配送資訊卡片加入「預計到貨」，不顯示配送進度圖。
- 訂單明細頁「備註」歸在配送資訊卡片，接續顯示於預計到貨後方。
- 訂單明細頁操作列在「聯絡客服」前顯示主要操作：待付款訂單顯示「前往付款」，非待付款訂單顯示「再買一次」。
- 訂單明細頁費用明細加入「折抵明細」，逐列顯示已使用的折價券、優惠碼、OP 點數折抵與購物金折抵。
- 訂單明細頁補上交易回查欄位：下單時間、指定送達時段、滿額加贈禮、付款期限、取消與退款資訊。
- 訂單列表展開商品明細時，顯示商品型號、規格與滿額加贈禮贈品列。
- 訂單列表有折抵時，在訂單金額下方顯示已含折抵金額。
- 不調整訂單建立流程、付款流程、配送方式計算、運費計算或訂單狀態邏輯。

## Acceptance Criteria

- checkout 有填希望配送日期時，訂單完成頁「預計到貨」顯示該日期。
- checkout 未填希望配送日期時，訂單完成頁「預計到貨」右側為空白。
- 訂單完成頁配送進度只顯示「訂單確認」「備貨中」「已送達」。
- 訂單明細頁配送資訊卡片不顯示配送進度圖。
- 訂單明細頁備註顯示於配送資訊卡片，不顯示於付款資訊卡片。
- 待付款訂單明細頁顯示「前往付款」按鈕，位置在「聯絡客服」前方。
- 非待付款訂單明細頁顯示「再買一次」按鈕，位置在「聯絡客服」前方。
- 有折價券、優惠碼、OP 點數或購物金折抵時，費用明細需顯示折抵來源名稱與金額。
- 沒有使用折抵時，費用明細顯示「未使用折抵」。
- 訂單資料區顯示訂單編號與下單時間。
- 配送資訊區顯示指定送達時段。
- 付款資訊區於待付款訂單顯示付款期限。
- 有滿額加贈禮時，整合在訂購商品清單底部以贈品列呈現，並顯示商品型號與規格；沒有贈品時不顯示。
- 已取消訂單顯示取消時間、取消原因與退款狀態。
- 訂單列表展開商品明細時，一般商品顯示商品型號與規格。
- 訂單列表展開商品明細時，有滿額加贈禮的訂單需顯示贈品列，贈品單價與小計為 $0。
- 訂單列表有折價券、優惠碼、OP 點數或購物金折抵時，訂單金額下方顯示已含折抵金額。
- 三個節點在桌機與手機版都平均分配，不擠壓或溢出。
- 頁面不顯示 API、backend、mock、尚未串接等工程說明。

## Vuetify Mapping

- 配送資訊卡片：`v-card`
- 資訊列：`v-row` / `v-col`
- 配送進度：可用 `v-stepper` 或自訂 `v-row` 搭配 `v-avatar` 與 divider
- 日期欄位來源：checkout 表單 snapshot 或正式訂單資料中的希望配送日期欄位

## Follow-up: 訂單明細欄位補齊

依既有正式站訂單明細截圖，原型訂單明細頁補上以下使用者可見欄位：

- 訂購人姓名、地址、市內電話、行動電話
- 收件人姓名、地址、市內電話、行動電話
- 刷卡結果、交易序號
- 發票種類、發票寄送方式
- 貨運單號、備註
- 商品型號

本次不新增指定送達時間、滿額加贈禮、商品總價表格欄名，以及宅配運費類型文字；保留原型既有「預計到貨」「小計」「運費」呈現。

組合商品呈現規則：

- 外層維持一筆訂購商品，顯示組合商品名稱、組合數量與組合小計。
- 內層以縮排表格列出組合內容，欄位包含商品型號、商品名稱、規格、數量。
- 不將組合內容拆成多筆一般商品列，避免使用者誤解為分開購買。

Vuetify mapping:

- 訂購人 / 收件人資訊：`v-card` + `v-row` / `v-col`
- 付款與發票資訊：`v-card` + `v-list` 或 `v-row`
- 商品型號：商品列內的次要文字，正式實作可用 `v-list-item-subtitle`
- 組合內容表格：`v-data-table` 或 `v-table`
