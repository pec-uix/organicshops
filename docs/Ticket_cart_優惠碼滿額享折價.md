# Ticket：購物車新增優惠碼滿額享折價示例

## 本次目的

在 `/cart` 的「折價券 / 折扣碼」區塊新增一組滿額享折價優惠碼示例。

本次只處理購物車頁前端原型呈現與折抵狀態，不新增活動專區入口。

## 調整範圍

| 區域 | 檔案 | 調整內容 |
|---|---|---|
| 購物車頁 | `src/views/CartView.vue` | 折扣碼資料支援金額與滿額門檻 |
| 購物車頁 | `src/views/CartView.vue` | 新增 `FULL1800`：滿 $1,800 折 $50 |
| 購物車頁 | `src/views/CartView.vue` | 未達門檻時顯示差額提示 |

## 顯示規則

- 輸入 `FULL1800` 且目前溫層商品小計達 $1,800 時，折抵 $50。
- 未達 $1,800 時，不套用折抵，並提示還差多少。
- 既有 `ORGANIC100`、`GREEN50` 維持原本無門檻折抵。

## 驗收條件

- `/cart` 折扣碼欄位輸入 `FULL1800` 可看到滿額折價提示或折抵金額。
- 達門檻後結帳明細顯示折扣碼折抵 $50。
- 未達門檻時不會折抵金額。
- `npm run build` 通過。
