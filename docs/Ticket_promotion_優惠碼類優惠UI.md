# Ticket：優惠碼類優惠 UI 呈現

## 目標

補齊優惠碼類優惠在目前 Vue prototype 的前台呈現，包含優惠碼滿額免運、優惠碼滿額送贈品、優惠碼滿額打折，並保留既有 `FULL1800`、`ORGANIC100`、`GREEN50` 的折抵行為。

## 範圍

- 購物車折扣碼輸入區支援不同優惠碼類型。
- 未達門檻時顯示還差多少。
- 達門檻時顯示已套用狀態。
- 免運優惠碼反映在運費列。
- 贈品優惠碼顯示贈品列。
- 打折優惠碼顯示折抵金額。
- 結帳摘要顯示優惠碼來源。
- 訂單回查顯示優惠碼折抵來源與贈品列。

## Mock 優惠碼

| 優惠碼 | 類型 | 門檻 | 呈現 |
| --- | --- | --- | --- |
| ORGANIC100 | 金額折抵 | 無 | 折抵 $100 |
| GREEN50 | 金額折抵 | 無 | 折抵 $50 |
| FULL1800 | 滿額折價 | 滿 $1,800 | 折抵 $50 |
| FREESHIP1800 | 滿額免運 | 滿 $1,800 | 運費顯示優惠碼免運 |
| GIFT1500 | 滿額送贈品 | 滿 $1,500 | 贈有機燕麥飲 |
| SAVE95 | 滿額打折 | 滿 $1,800 | 享 95 折 |

## 驗收標準

- 購物車輸入未達門檻優惠碼時，能看到尚差金額。
- 達門檻優惠碼會顯示已套用文案。
- `FREESHIP1800` 達門檻後運費列顯示優惠碼免運。
- `GIFT1500` 達門檻後購物車與結帳摘要顯示贈品列。
- `SAVE95` 達門檻後購物車與結帳摘要顯示折抵金額。
- 訂單回查可看到優惠碼折抵來源與優惠碼贈品列。

## Vuetify 對應建議

- 優惠碼輸入：`v-text-field` + `v-btn`
- 套用狀態：`v-alert` 或 `v-chip`
- 贈品列：`v-list-item`
- 運費與折抵明細：`v-card` + `v-list`
- 訂單折抵明細：`v-data-table` 或 responsive `v-list`
