# Design Pass: 聯絡客服 Banner 調整

## 範圍

- 頁面：`/contact`
- 檔案：`src/views/ContactView.vue`

## UI 調整

- 頁首改為與 `/news` 一致的 Banner 呈現。
- 使用 `images/背景圖.png` 作為背景圖，並搭配柔和白色漸層。
- 標題與副標題改為深色字系，提升在明亮背景上的可讀性。
- 保留原本的聯絡資訊區、FAQ 引導與表單內容。

## Acceptance Criteria

- `/contact` 首屏呈現 Banner。
- 標題與副標題在 Banner 上清楚可讀。
- 既有聯絡表單與側欄內容維持不變。
- 畫面不出現工程註記。
