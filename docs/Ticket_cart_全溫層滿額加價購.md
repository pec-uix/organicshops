# Ticket：/cart 頁全溫層自適應滿額加價購商品區塊

## 本次目的

將購物車頁既有加價購專區，調整為依目前溫層動態分流的滿額加價購區塊。

目標是讓使用者切換常溫、冷藏、冷凍、產地直送時，只看到該溫層可一併配送的加價購商品，避免跨溫層加購造成結帳與配送理解混亂。

## 調整範圍

| 區域 | 檔案 | 調整內容 |

| 購物車頁 | `src/views/CartView.vue` | 替換舊版加價購區塊 |
| 購物車頁 | `src/views/CartView.vue` | 依 `activeZone.key` 顯示對應溫層加價購商品 |

| 購物車頁 | `src/views/CartView.vue` | 加價購商品列表改為固定卡寬，桌機一列最多五張 |

## 顯示規則

- 加價購區塊放在目前溫層購物車主卡片下方。
- 無 `activeZone` 或目前溫層沒有商品時，不顯示本區塊。
- 加價購商品只顯示與目前溫層相同的品項。
- 未達門檻的加價購商品不顯示。
- 目前溫層小計達到商品門檻後，該商品才出現在加價購區塊。
- 商品名稱固定兩行高度，避免商品卡因文字長短造成高度不一致。
- 商品卡固定寬度為 `220px`，不因單列商品數量少而撐滿整列。
- 桌機版容器以固定卡寬排列，一列最多五張商品卡。
- 手機版維持固定卡寬並允許水平瀏覽，避免卡片被壓縮或撐滿全寬。
- 區塊外層使用低彩度品牌底色，與上方購物車主卡片形成層級。
- 標題左側使用品牌綠垂直裝飾線，並保留低干擾副標。
- 不顯示鎖定卡、差額提示或達標提示。
- 商品圖片可連到對應商品詳情頁。

## 數量彈窗規則

- 點擊加價購商品的加入按鈕時，先開啟數量選擇彈窗。
- 數量預設為 1。
- 單次加購數量最少 1、最多 10。
- 確認加入後，才橋接既有 `cart/addItem`。
- 加入商品時帶入 `quantity`，讓既有 cart mutation 依數量加入商品。
- 關閉或取消彈窗時，清除目前選取商品與數量。

## 溫層對應

| TempZone | 顯示名稱 |
|---|---|
| `ambient` | 常溫 |
| `chilled` | 冷藏 |
| `frozen` | 冷凍 |
| `fresh` | 產地直送 |

## 不在本次處理

- 不調整 `CartDrawer.vue`。
- 不調整 `CheckoutView.vue`。
- 不調整 Vuex cart store 計價、折扣、運費、OPENPOINT 點數或結帳計算邏輯。
- 不處理正式優惠規則與後台資料維護流程。

## Vuetify 對應建議

- 外層區塊：`v-card`
- 商品卡：`v-card`
- 狀態標籤：`v-chip`
- 加入按鈕：`v-btn`
- 未達門檻的品項不渲染，達門檻後才顯示。

## 驗收條件

- 切換溫層時，只顯示目前溫層加價購商品。
- 未達門檻的加價購商品不出現在畫面上。
- 達門檻後，加價購商品才出現在目前溫層加價購區塊。
- 點擊加入按鈕，會先開啟數量選擇彈窗。
- 彈窗數量控制限制為 1 到 10。
- 加價購商品加入後，出現在同一溫層商品清單中。
- 加價購商品金額自然納入目前溫層小計、免運進度與結帳明細。
- 點擊加價購商品圖片，可進入對應商品詳情頁。
- 商品卡固定寬度，不因目前溫層加價購商品數量不同而改變卡片大小。
- 桌機版滿額加價購一列最多五張商品卡。
- 手機版商品卡不壓縮、不重疊。
- 前台畫面不出現工程提醒語氣。
- `npm run build` 可通過。
