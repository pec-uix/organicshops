# Design Pass: 最新消息清單頁排版調整

## 範圍

- 頁面：`/news`
- 頁面：`/news/:id`
- 檔案：`src/views/NewsListView.vue`
- 檔案：`src/views/NewsDetailView.vue`
- 目標：參考正式站最新消息頁的資訊架構，改為清單優先的消息列表，同時維持 prototype 首頁的品牌視覺語言。

## UI 調整

- 頁首使用明亮自然主視覺，搭配柔和白色漸層與深色文字，保留「最新消息」作為第一視覺焦點。
- Banner 文字容器使用明確的相對定位與 z-index，確保標題不被漸層層遮擋。
- 增加麵包屑區塊：首頁 / 最新消息。
- 頁面不提供分類切換，讓使用者直接瀏覽全部消息清單。
- 消息文字改以統一生機購物網近期最新訊息為參考，建立更接近實際營運情境的公告、優惠、會員服務、配送服務與食安聲明內容。
- 消息內容由圖卡網格改為緊湊型扁平卡片清單：
  - 左側品牌綠圓形日期徽章
  - 消息標題
  - 單行簡短摘要
  - 進入詳情箭頭
- 手機版清單改為上下堆疊，避免日期方塊與標題擠壓。
- 清單容器限制為 `max-w-6xl`，並使用每則獨立 1px 淺灰邊框卡片，讓消息區隔更清楚。
- 清單每頁顯示 12 筆，超過單頁筆數時底部提供上一頁、頁碼、下一頁。
- 目前 mock data 提供 14 筆消息，用於呈現兩頁分頁狀態。
- 消息詳情頁改為正式站文章型結構：
  - 麵包屑
  - 置中文章標題
  - 日期置中
  - 分隔線
  - 文章摘要與正文
  - 其他消息
- 詳情頁主文章區不使用外框卡片，讓內容直接呈現在頁面中。
- 詳情頁主文章區與「其他消息」同為 `max-w-5xl` 視覺寬度，主文章不額外加水平 padding，避免內容邊界內縮。

## Design Consistency

- 沿用既有品牌色：
  - `brand-primary`
  - `brand-dark`
  - `brand-bg`
  - `brand-surface`
- 沿用首頁章節標題語氣：
  - 左側品牌綠線
  - 高字重中文標題
  - 小字距輔助資訊
- 清單容器使用既有圓角、白底與細邊框卡片風格。
- 可點擊列使用 hover 狀態提示，不在畫面上呈現工程或資料限制說明。

## Vuetify Mapping

- 頁首容器：`v-container` 搭配背景區塊
- 麵包屑：`v-breadcrumbs`
- 分類章節列：`v-tabs` 或 `v-slide-group`
- 消息清單：`v-list` / `v-list-item`，或 `v-card` 包覆多個 list rows
- 進入詳情箭頭：`v-btn` icon variant

## Acceptance Criteria

- `/news` 第一屏可清楚辨識為最新消息頁。
- 消息清單直接呈現全部內容，不顯示分類導覽或清單上方摘要區。
- 超過單頁筆數時，底部顯示分頁控制，並可切換頁碼更新清單內容。
- 列表項目點擊後維持導向 `/news/:id` 詳情頁。
- 桌機與手機版文字不重疊、不溢出。
- 畫面不出現 API、mock、backend 等工程提示文字。
