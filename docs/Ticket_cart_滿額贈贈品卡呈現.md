# Ticket：/cart 頁滿額贈贈品插入正常商品清單呈現

## 本次目的

將購物車頁常溫滿額贈達標後的贈品內容，視覺上插入常溫商品清單內，讓贈品看起來像隨常溫訂單一併帶入的商品列。

本次僅處理 `/cart` 頁前端視覺渲染，不將贈品加入 Vuex cart store，也不影響結帳金額、折扣、運費或 OPENPOINT 點數。

## 調整範圍

| 區域 | 檔案 | 調整內容 |
|---|---|---|
| 購物車頁 | `src/views/CartView.vue` | 常溫滿額贈達標後在商品清單內顯示 3 筆贈品列 |
| 購物車頁 | `src/views/CartView.vue` | 達標文字縮短，贈品明細改由商品列承接 |

## 顯示條件

- 僅在目前溫層為常溫 `ambient` 時顯示。
- 常溫商品小計達 `1500` 元後顯示贈品列。
- 未達 `1500` 元時維持差額提示，不顯示贈品列。
- 空購物車或目前常溫沒有商品時不顯示。

## 插入位置

- 贈品列插入在常溫 `activeZone.items` 正常商品列之後。
- 贈品列與正常商品共用同一個列表容器與分隔線語氣。
- 視覺順序為：正常商品列、贈品列、免運 / 滿額進度條、折價券 / 結帳明細。

## 贈品內容

| 贈品 | 規格 | 數量 |
|---|---|---|
| 海苔薄切洋芋片 | 59.5公克/包 | 2 |
| 杏桃乾 | 200公克/包 | 1 |
| 原味腰果隨手包 | 30g/包 | 1 |

## 視覺規格

- 贈品列沿用正常購物車商品列的圖片、資訊、單價與小計欄位節奏。
- 「贈品」標籤顯示在商品名稱前方。
- 規格顯示在與正常商品 `unit` 相同的位置。
- 數量顯示在與正常商品數量控制相同的位置，但為唯讀外框，不顯示加減按鈕。
- 每列顯示贈品圖示、贈品名稱、規格、數量、`$0` 與「贈品」標籤。
- 不顯示可操作的數量加減器、刪除按鈕或加入購物車按鈕。
- 手機版沿用正常商品列換行方式，桌機版欄位對齊正常商品列。

## 不在本次處理

- 不修改 `CartDrawer.vue`。
- 不修改 `CheckoutView.vue`。
- 不修改 Vuex store。
- 不將贈品 dispatch 到 `cart/addItem`。
- 不將贈品 push 進 `activeZone.items`。
- 不調整價格、折扣、運費、OPENPOINT 點數或結帳計算邏輯。

## Vuetify 對應建議

- 贈品列：可沿用購物車商品列的 `v-row` / `v-col` 結構
- 贈品標籤：`v-chip`

## 驗收條件

- 常溫小計未達 `1500` 元時，不顯示贈品列。
- 常溫小計達 `1500` 元後，在正常商品清單內顯示三筆贈品列。
- 常溫滿額贈達標提示顯示「滿額贈：已成功獲得贈品！「海苔薄切洋芋片x2包 + 杏桃乾(袋)x1包 + 原味腰果隨手包x1包」」。
- 三筆贈品列分別顯示海苔薄切洋芋片數量 2、杏桃乾數量 1、原味腰果隨手包數量 1。
- 「贈品」標籤顯示在商品名稱前方。
- 贈品規格顯示在商品規格位置。
- 贈品數量顯示在唯讀數量欄，沒有加減按鈕。
- 贈品列顯示 `$0`，沒有加入購物車按鈕或刪除按鈕。
- 贈品不進入 Vuex cart store，也不影響結帳計算。
- `npm run build` 可通過。
