# Design Pass: 特約店頁排版調整

## 範圍

- 頁面：`/stores`
- 檔案：`src/views/StoresView.vue`

## UI 調整

- 頁首改為與站內其他內容頁一致的 Banner 結構，使用自然明亮的背景圖與深色主標。
- 增加麵包屑導覽，讓頁面脈絡與首頁、最新消息、聯絡客服等頁一致。
- 內容主體改為參考網站式查找版面：
  - 上方城市切換按鈕列，底部加淡灰分隔線，並在捲動時 sticky 固定於頁面上方
  - 下方 `1200px` 置中的特約店清單
  - 每間特約店以單張完整卡片呈現，卡片內直接包含該地址的地圖
  - 桌機版卡片分為品牌招牌、店家資訊、地址地圖三欄，招牌區較寬、地圖作為輔助區
- 城市互動分為兩種狀態：
  - 全部顯示時點縣市 tab，左側清單平滑捲動到該縣市
  - 單一縣市顯示時點縣市 tab，直接切換篩選內容
- 特約店卡片採白底、`#E5E7EB` 細邊框、4px 微圓角，維持清楚的區隔性。
- 卡片前方增加品牌化店名招牌區，以網站主題色重做參考頁的圖片入口感。
- 地圖改為每個地址各自顯示，不再使用單一總覽地圖，降低互動理解成本。
- 卡片移除操作按鈕、副標說明與重複標籤，讓店名、地址、電話與地圖成為主要閱讀內容。
- 城市下方仍依行政區整理卡片順序，但不顯示行政區小標題；地址以完整文字同色呈現。
- 城市切換按鈕以品牌綠為選取態，未選取態保留灰白底，方便快速辨識目前篩選範圍。
- 移除快速瀏覽文字列表與篩選說明，避免和卡片清單重複。
- 移除特約店服務提醒，讓清單區直接進入縣市與行政區資訊。
- 整體容器與其他內容頁對齊，避免在大螢幕下拉得過寬。
- 門市資料改以 `page.aspx?page=place` 的特約店清單為準，包含城市分組、店名、地址與電話。
- 不額外加入官方頁面未列出的營業時間欄位，維持資訊來源一致。

## Design Consistency

- 沿用既有品牌色：
  - `brand-primary`
  - `brand-dark`
  - `brand-bg`
  - `brand-surface`
- 標題語氣與其他內容頁一致，維持左側 4px 品牌綠線、小段說明、白底卡片的結構。
- 卡片圓角、邊框與按鈕維持輕量，避免門市頁看起來偏向工具頁或地圖頁。

## Vuetify Mapping

- Banner：`v-container`
- 麵包屑：`v-breadcrumbs`
- 城市切換：`v-tabs` 或 `v-chip-group`
- 門市卡片：`v-card`
- 地址地圖：`v-responsive` / `v-card` 內嵌地圖 iframe

## Acceptance Criteria

- `/stores` 首屏可清楚辨識為特約店頁。
- 全部顯示狀態下，可依城市 tab 定位左側清單。
- 單一縣市狀態下，可依城市 tab 切換篩選內容。
- 門市資訊以完整卡片堆疊呈現，桌機與手機版都能清楚閱讀。
- 卡片依行政區排序，地址維持完整文字閱讀。
- 每張特約店卡片都直接顯示對應地址地圖。
- 頁面不再出現快速瀏覽重複列表或篩選文字說明。
- 畫面維持目前網站的自然清新主題，不出現工程提示文字。
