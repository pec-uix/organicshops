# Design Pass: 聯絡客服內容調整

## 範圍

- 頁面：`/contact`
- 檔案：`src/views/ContactView.vue`

## UI 調整

- 頁首維持與 `/news` 一致的 Banner 呈現。
- 聯絡資訊改為參考統一生機 `service.aspx` 的資料內容：
  - 客服專線 0800-777-000
  - 愛用者免付費電話 0800-880-988
  - LINE 客服 @upoc
  - 公司名稱、統編、電話、傳真、地址
- 右側表單改成更接近客服回覆系統的欄位結構：
  - 聯絡人
  - 手機
  - 地址
  - 傳真
  - 電子信箱
  - 問題類型
  - 諮詢內容
  - 個資條款勾選
- 整體保留本站既有的圓角、淺灰底、品牌綠與卡片層次。
- 本公司聯絡資訊移至表單下方，以橫向兩欄資訊列呈現。
- 左側卡片只保留客服專線。
- 右側卡片只保留 LINE 客服與 QR code。
- 常見問題區塊移至最底部。

## Acceptance Criteria

- `/contact` 呈現 Banner 與客服資訊。
- 內容資料與統一生機客服頁接近，但視覺維持本站版型。
- 表單欄位可正常送出與驗證。
- 畫面不出現工程註記。
